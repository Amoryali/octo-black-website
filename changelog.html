Version Changelog

Track all updates, core improvements, and feature additions.

v1.0.0 — Initial Official Release

Released: November 4, 2026
  • Official release of Octo Black Android frontend.
  • Bundled 9 runtime-verified ARM64 emulator cores (NES, SNES, N64, PS1, Genesis, Atari 2600, GBA, PSP, NDS).
  • Implemented automatic ROM directory scanner and media cache.
  • Integrated CWCheat database and manual cheat entry.
  • Custom touch gamepad layout editor with analog input throttling.
  • Full English & Arabic bilingual support with RTL layout engine.

v1.0.1 — Dreamcast Widescreen & Controls Update

Released: Early November 2026
  • New — 16:9 widescreen mode for Dreamcast games, fitted perfectly to modern phone screens.
  • Fixed — on-screen controller buttons for Dreamcast now respond correctly: START, A, and D-pad.
  • Improved — overall stability and performance across all supported systems.
  • Updated — version information and download files to v1.0.1 (build 2).
  • Website — improved the bilingual changelog and fixed the Arabic/English language switcher.

v1.0.2 — Cheat Codes Redesign & Touch Layout Editor

Previous Release
  • New — a pencil button inside the gameplay screen pauses the emulator, opens the touch control layout editor, then resumes play from where it stopped.
  • New — redesigned Cheat Codes screen with search, All/Active filters, an active counter, unified switches, Database and My Cheats sections, expandable code lines, and edit/delete for manual cheats with confirmation.
  • Improved — both controller shoulder buttons unified into one symmetric position, with the default corner layout restored like classic consoles.
  • Improved — library header and sorting options, plus removed the black backing from game cover artwork.
  • Fixed — LateInitializationError when reloading runtime settings.
  • Translation — full Arabic coverage for the cheat screens and the gameplay quick menu.
  • New — the game covers are now a new 3D box style.

v1.0.3 — Nintendo Wii & Dolphin Update

Current Release
  • New — Nintendo Wii support via the official Dolphin Libretro core (arm64), with system files (Sys) extracted automatically on first launch — no BIOS required.
  • Note — the Dolphin (Nintendo Wii) emulator does not work yet; it has only been added to the app and will be enabled in a future update.
  • New — Nintendo Wii now appears on the home screen system strip.
  • Improved — smarter ROM scanner: .wbfs/.gcz/.rvz/.wia/.ciso and .nkit.iso files are classified automatically, while ambiguous .iso files are identified only by a [Wii] token in the file name (never the folder name) so PSP dumps are never mislabeled.
  • Fixed — previously saved ROM entries are re-classified correctly (e.g. .nkit.iso files stuck as Unknown).
  • Fixed — Dolphin system files (Sys) now extract to the correct path on first launch.
  • Improved — redesigned Developer card in Settings with a new WhatsApp contact button.
  • Updated — version information and download files to v1.0.3 (build 4).
